# 车辆模块设计（V1 已实现，V2 待排期）

## 1. 问题与目标

车相关的事原来散在三处：储藏 → 装备 → 汽车装备（只记数量位置）、房屋耗材 → 汽车养护（机油、玻璃水）、账单 → 车险 / 车贷 / 停车费。缺的是**生命周期**：按里程或时间的保养、牌照年贴、排放检测、保险续保、保修与租赁到期、换车。

目标：用最少的新结构把车纳入现有的“设备档案 + 保养记录 + 提醒总线”，油车和电车用同一套表单、不同的保养模板。

## 2. 模型：车是挂在家庭上的一种设备

- `assets.kind` 增加 `vehicle`；`assets.property_id` 对车辆允许为空（车跟人走，卖房不卖车）。
- `assets.type` 即动力类型：`vehicle_gas` 油车、`vehicle_hybrid` 混动、`vehicle_phev` 插混、`vehicle_ev` 纯电。它决定保养模板，不影响其他结构。
- 复用已有字段：`brand` 品牌、`model` 型号、`manufacture_year` 年款、`serial` = VIN、`installed_on` = 购车日期、`purchase_price`、`warranty_until` 整车保修、`labor_warranty_until` = 动力总成 / 高压电池保修、`notes`。
- 车辆专有字段放 `assets.vehicle jsonb`：

```json
{ "plate": "ABC 1234", "plate_state": "IL", "odometer": 48200, "odometer_on": "2026-10-01", "annual_miles": 12000,
  "registration_due": "2027-03-31", "emissions_due": "2027-06-30", "lease_end": null,
  "insurance": { "provider": "State Farm", "policy": "…", "from": "2026-05-05", "to": "2026-11-05", "coverage": "…", "agent": "…", "phone": "…", "email": "…" } }
```

- 保险块和房屋资料的保险块同构，同一保单号的多辆车在首页合并成一条续保提醒；账单里的“车险”继续负责缴费提醒。

## 3. 保养模板（data/vehicles.js）

每个保养项：`{ key, name, months, miles, powertrains, note }`。到期取“按月”和“按里程”两者中较早的；里程到期日用年均里程把剩余里程换算成天数。

| 项目 | 适用 | 周期 |
|---|---|---|
| 机油机滤 | 油车、混动、插混 | 6 个月 / 5,000–7,500 英里（全合成 10,000） |
| 轮胎轮换 | 全部（电车更要紧） | 6 个月 / 6,000 英里 |
| 空调 / 车内滤芯 | 全部 | 12 个月 / 15,000 英里 |
| 发动机空滤 | 油车、混动、插混 | 24 个月 / 30,000 英里 |
| 刹车油 | 全部 | 36 个月 |
| 火花塞 | 油车、混动、插混 | 100,000 英里 |
| 变速箱油 | 油车、混动、插混 | 60,000 英里 |
| 冷却液 | 全部（电车为电池冷却液） | 60 个月 / 60,000 英里 |
| 12V 小电瓶 | 全部（电车 3–4 年必换） | 48 个月 |
| 电池健康度记录 | 纯电、插混 | 12 个月 |
| 充电设备检查 | 纯电、插混 | 12 个月 |
| 召回查询（NHTSA 按 VIN） | 全部 | 12 个月 |
| 雨刮片 | 全部 | 12 个月 |
| 四轮定位 | 全部 | 24 个月 |

保养记录增加 `service_item`（对应上表的 key）和 `odometer`；某一项的下次到期从该项最近一条记录算起，没记录就从购车日期 / 当前里程算起。

## 4. 提醒（接入提醒总线）

| 事项 | 级别 |
|---|---|
| 牌照年贴、排放检测、保险到期前 30 天 | 尽快（必须）；过期 → 今天 |
| 保养项按日期或里程到期 | 尽快；逾期 → 今天 |
| 保修到期前 60 天、租赁到期前 90 天 | 留意 |
| 检查记录结论为“需维修 / 需更换”且之后没有维修记录 | 尽快（必须） |

伊州 / 芝加哥：牌照年贴每年；排放检测车龄 4 年以上每两年，纯电免；Chicago city sticker 另建账单。

## 5. 页面

- 房屋 → 车辆：所有车辆的卡片（年款 品牌 型号、车牌、里程、动力类型、最近三项要做的保养、牌照 / 保险状态），不显示房产切换条。
- 添加 / 编辑：复用设备整页表单；选“车辆”种类后出现车辆专有区块（车牌、里程、年均里程、牌照 / 排放 / 租赁到期、保险）。
- 保养记录表单对车辆多“保养项目”和“里程”两个字段；花费记入“车辆”统计组。
