# 税务（Tax）模块设计：提醒、归集、年度报税参考

状态：**设计稿（2026-11-22），未实现**。待确认的问题见第 11 节。
定位：**参考工具，不是报税软件，也不是税务建议。** 真正报税仍在 TurboTax 里做；这里负责「一年到头别漏事」「报税时手边材料齐、数字现成」「重大事件（买卖房产、车辆、股票、国外汇款）发生时知道会碰到什么税」。

## 1. 问题与目标

**问题**

- 税的事散在全年：收入（W-2、利息、租金、卖股票）、支出（房贷利息、房产税、捐款、医疗）、资产买卖（房、车、股票）、海外账户和汇款。到了 3–4 月才回头翻，容易漏单据、漏申报项。
- 家里的身份比较特殊：**美国税务居民（resident alien）、非美国公民、夫妻合报（Married Filing Jointly），联邦 1040 + 伊利诺伊州 1040-IL，用 TurboTax**。有几类事只有这类家庭会碰到（海外账户申报、境外收入、境外赠与…），普通指南里不讲。
- 小助手里其实已经有大部分原料：收入账本（类型、到账账户）、花费（分类、经济性质）、借贷（房贷本金 / 利息拆分、Escrow）、房产和车辆（买入价、卖出价、交易记录）、卡与账户（余额历史）、账单（房产税、保险）。缺的是「按税的视角重新看一遍」和「提醒」。

**目标**

1. **知道有哪些点**：按「收入 / 支出 / 资产 / 账户 / 家庭」列出可能关系到税的事项，每项一句话讲清「为什么相关、要留什么单据、报在哪张表」。
2. **该做的时候提醒**：全年日历（预缴税、1099 到齐、FBAR、报税截止、延期…）进「今日」注意事项；重大事件（卖房、卖车、卖股票、收到国外汇款）发生时弹出对应指南。
3. **报税季的工作台**：每年一份清单 + 一张「数字汇总表」（工资、利息、股息、卖出收益、房贷利息、房产税、捐款…各多少，数字来自家里已有的记录），对照 TurboTax 的各个页面逐项抄；缺的单据一眼看到。
4. **安全**：不存 SSN / ITIN / PIN / 银行路由号和账号 / IP PIN；只存「有没有、放在哪」。

**成功标准**

- 报税季打开「税务」页，3 分钟内知道：还缺哪几张单据、哪些数字要自己核对、有哪些「容易漏」的项目没处理。
- 卖房 / 卖车 / 卖股票前后，页面上能看到对应指南和需要保存的记录，不用再去搜。
- 任何页面、备份、AI 对话里都不出现个人证件号和 PIN。

## 2. 范围与非目标

**范围**：联邦 1040（含常用附表）与伊利诺伊 IL-1040；提醒、清单、数字汇总、事件指南、海外账户与境外收入的阈值跟踪；每个税务年度一份。

**非目标**

- 不算应缴税额、不算退税、不替代 TurboTax；不电子报税。
- 不存任何证件号 / PIN / 报税软件账号密码。
- 不给个性化税务建议（App 层面写明；复杂情况建议问 CPA）。
- 不做 W-2 / 1099 的 OCR 入库（二期以后再评估，且要先过隐私评估）。
- 不处理企业 / 自雇的完整税务（只提示 1099-NEC / Schedule C / 预缴）。

## 3. 家庭情境（影响整个模块的前提）

| 项 | 取值 | 对模块的影响 |
|---|---|---|
| 税务身份 | Resident alien，非美国公民 | **全球收入都要报**（包括国外银行利息、国外房产租金），不只是美国收入；有境外账户 / 资产的额外申报（FBAR、Form 8938） |
| 报税身份 | Married filing jointly | 夫妻合并：门槛按合报计算（FBAR 汇总、8938 阈值、各项扣除） |
| 联邦 / 州 | 1040 + IL-1040 | IL 是单一税率；有 IL 特有的抵免（如房产税抵免） |
| 软件 | TurboTax | 汇总表按 TurboTax 的访谈顺序排（收入 → 扣除 → 抵免 → 其他），说明「在哪一页填」 |
| 数据来源 | 小助手里的收入 / 花费 / 借贷 / 资产 / 账户 | 做数字汇总；不连银行 |

> 前提要确认：两位是否都是税务居民、是否有人是「按住满天数」（substantial presence）而非绿卡、是否有 ITIN 的家属——这些会改变合报资格和部分规则，见第 11 节。

## 4. 税务相关点清单（评估）

下面是「可能涉及税」的点，按小助手里已有的数据位置分组。**数字阈值和细则每年会变，不写死在代码里，放进带年份和出处的数据文件（第 7 节）；表中的数字是 2025 年前后的大致量级，实施时逐项核对 IRS / IL DOR 原文。**

### 4.1 收入（对应：财务 / 收入）

| 项 | 为什么相关 | 要留的单据 / 表 | 小助手现状 |
|---|---|---|---|
| 工资（W-2） | 联邦 + IL 都要报；预扣税对账 | W-2；W-4 | 收入类型有工资，可汇总到账金额，但**税前总额 / 已扣税**需要从 W-2 单独录入 |
| 银行利息 / 股息 | 美国账户有 1099-INT / DIV；**国外账户的利息同样要报** | 1099-INT / DIV；国外银行对账单 | 收入类型有利息；要区分美国 / 境外 |
| 卖股票 / 基金 | 资本利得（短期 / 长期） | 1099-B；Form 8949、Schedule D | 收入类型有「卖出类 + 其中已实现收益」，可汇总；成本基础需核对 1099-B |
| 租金收入 | 房产「用途」是出租时：Schedule E，折旧，可扣费用 | 租约、收租记录、费用单据、房产买入价（折旧基础） | 房产有用途 / 买入价；收租和费用在账单里 |
| 自由职业 / 1099-NEC | 自雇税，要预缴 | 1099-NEC / K；Schedule C / SE | 收入类型可标，但无预缴提醒 |
| 个人赠与 / 借款（资本流入） | 国内赠与一般不是收入；**收到境外亲友的大额赠与要申报（Form 3520，超过门槛）** | 转账记录、赠与说明 | 收入账本已有「资本与资产流入」类型（不算收入），可加「境外来源」标记和年度累计 |
| 退税 / 报销 | 州退税在联邦可能要报；报销不算收入 | 1099-G | 已有「退款 / 报销」处理 |
| 退休 / HSA 供款 | 影响应税收入（401K 税前、HSA 税前、IRA 视收入） | 年度供款额、Form 5498 / 8889 | 账户有退休 / HSA 类型；缺「年度供款」记录 |

### 4.2 支出（对应：财务 / 花费、账单、借贷）

| 项 | 为什么相关 | 要留的单据 / 表 | 小助手现状 |
|---|---|---|---|
| 房贷利息 | 逐项扣除（Schedule A）的重要来源，只有逐项才有用 | 1098 | **借贷已按摊还表拆本金 / 利息**，可直接汇总全年利息（与 1098 对账） |
| 房产税 | Schedule A（SALT 有上限，上限随年度政策变化）；**IL 另有按房产税的抵免** | 房产税账单 / Escrow 年度对账（1098 里也有） | 账单有「房产税」类别，Escrow 代缴已有 |
| 医疗支出 | 逐项扣除，超过 AGI 一定比例才有用；HSA/FSA 另算 | 收据、EOB | 有一次性医疗账单（可勾 HSA 可用） |
| 慈善捐款 | 逐项扣除 | 捐款收据（现金 / 物品） | 花费分类里有无「捐款」要核对，建议加「税务标记」 |
| 州税 / 其他税 | 同属 SALT | 缴款记录 | 收入 / 花费里的 income_tax 账单类别 |
| 教育 / 儿童看护 | 抵免（如儿童看护、教育抵免）；IL 有 529 扣除 | 收据、1098-T、托管账户对账 | 需要加标记；有无资格要按家庭情况判断 |
| 预缴税（1040-ES / IL-1040-ES） | 有自雇 / 投资 / 租金收入、预扣不够时要预缴，晚了有罚款 | 缴款确认号 | 账单类别有「income_tax」（季度），可作为预缴提醒入口 |
| 家用办公 / 车辆费用 | 只有自雇才可能扣；受雇员工一般不能 | 里程记录 | 车辆有里程；默认不提示，只在有自雇收入时提示 |

### 4.3 资产与重大事件（对应：房屋 / 交易、车辆）

| 事件 | 税务要点（概要） | 需要保存的记录 | 小助手现状 |
|---|---|---|---|
| **卖自住房** | 满足「近 5 年住满 2 年」可排除一定额度的收益（单身 / 合报额度不同）；超出部分是资本利得；可能收到 1099-S | 买入价、卖出价、交易费用、**装修翻新（计入成本基础）**、住满时间线 | 房产有买入 / 卖出价、状态、交易流程；缺「装修 / 改善记录」和「住满天数」 |
| **买房** | 交割单（HUD / CD）里的积分点、房产税预付、贷款费用的处理；首年的 1098 | 交割单 | 交易流程里有买房，可加「交割单要存」清单项 |
| **出租 / 自住转出租** | 折旧、租金申报；以后卖出要「折旧回收」 | 转租日市价、折旧记录 | 房产有用途；缺折旧 |
| **卖车** | 自用车一般是亏损 → **不能抵税**；如果卖价高于买价要报收益；如果车曾用于生意另算 | 买入价、卖出价、过户文件 | 车辆有买入价 / 卖出价 / 交易流程 |
| **买电车 / 新能源车** | 联邦曾有购车抵免，**政策近期有变，是否可用要看购买日期和车型，不要凭印象** | 购车合同、车辆资格声明 | 车辆类型含电车；只放「政策待核对」的提示 |
| **买房 / 买车贷款** | 利息处理见 4.2；车贷利息一般不可扣（自用） | 贷款对账单 | 借贷已覆盖 |
| **卖股票 / 加密货币** | 见 4.1；加密货币在 1040 首页有问题要如实回答 | 交易记录 | 暂无加密货币记录 |
| **赠与别人大额钱** | 年度免申报额度之内不用报；超过要报赠与税申报表（不一定要交税） | 转账记录 | 无 |

### 4.4 账户与海外资产（对应：财务 / 账户）— **这个家庭最该关注的一块**

| 项 | 要点 | 小助手现状 |
|---|---|---|
| **FBAR（FinCEN 114）** | 美国税务居民，**境外金融账户在一年中任何时点合计超过 1 万美元**（所有境外账户的**最高余额**加总，夫妻各自的账户都算）就要申报；4 月中旬到期、可自动延期；不是随 1040 提交，是单独在线申报 | 账户有余额历史；**缺「是否境外账户」标记和「当年最高余额」** |
| **Form 8938（FATCA）** | 随 1040 提交，门槛比 FBAR 高且按「年末 / 全年最高」两个口径、按居住地和报税身份分档；两者要求不同、可能同时要报 | 同上，需要境外资产清单（账户 + 部分境外投资 / 保险） |
| **境外收入与外国税** | 全球收入都要报；已在国外交的税可能有抵免（Form 1116）或扣除 | 收入类型可标「境外来源」 |
| **境外房产** | 租金收入要报；买卖有收益；价值可能要进 8938 | 房产可标「境外」 |
| **美国账户** | 利息 / 股息 1099；退休账户（IRA / 401K）的供款、转换、取款各有表 | 账户有退休 / HSA / 券商类型 |
| **汇款 / 转账** | 收到大额境外赠与要申报（Form 3520，门槛以当年规定为准）；汇出通常不涉税，但要留记录 | 收入账本已有国际电汇字段（原币种、手续费） |

### 4.5 家庭（对应：设置 / 家庭与成员）

家属的 SSN / ITIN 状况、年龄（儿童税收抵免）、是否被抚养、是否是 resident alien — **只记标记，不记证件号**。出生 / 领养新成员：提醒办 SSN、更新 W-4、重新评估抵免。

## 5. 方案总览

在**财务**下新增一个目录页「税务」（排在「账户」旁边），分五块：

1. **今年**（默认页）：本年度状态卡 + 下一个截止日 + 单据清单进度 + 「容易漏」提示。
2. **日历与提醒**：全年税务日历；进「今日」注意事项（沿用现有提醒总线，不另造）。
3. **单据与汇总**：本年度要收的单据清单（W-2、1099-INT/DIV/B、1098、1099-S、1095-A 等）+ 数字汇总表（按 TurboTax 访谈顺序）。
4. **事件指南**：买房 / 卖房 / 买车 / 卖车 / 卖股票 / 收到境外赠与 / 出租 / 新生儿 / 换工作……每个一页：「会碰到什么税 → 现在要做什么 → 要存什么」，并链接到小助手里对应的记录。
5. **知识库**：「X 是什么、谁要报、报在哪张表、截止日」的简明说明（全部来自数据文件，附官方出处链接和「最后核对日期」）。

### 5.1 提醒（挂在现有的提醒总线）

| 提醒 | 触发 |
|---|---|
| 1 月中旬：Q4 预缴截止（如适用） | 家庭有自雇 / 投资 / 租金收入标记 |
| 1 月底前：W-2 / 1099 应到齐 | 每年固定；对照单据清单催缺的 |
| 2–3 月：1098、1099-S、1095-A 等到齐 | 同上 |
| 3 月：开始汇总（打开工作台）、检查「容易漏」 | 每年固定 |
| 4 月中旬：联邦 / IL 报税截止；FBAR 截止（可自动延期） | 固定；有境外账户才提示 FBAR |
| 4 / 6 / 9 月：预缴截止（如适用） | 同 1 月 |
| 10 月中旬：延期后的截止 | 已延期时 |
| 事件触发：卖房 / 卖车 / 卖股票 / 收到境外汇款 | 交易流程完成、收入记为「卖出类」或「境外来源」时，弹对应事件指南入口 |
| 阈值触发：境外账户合计将超 FBAR 线 | 账户余额更新后重算 |

日期不写死：从数据文件按年度读，遇到周末 / 节假日顺延的规则也在数据文件里。

## 6. 数字汇总表（工作台的核心）

每一行：**项目 / 本年度数字 / 来源（点开看明细）/ 对应 TurboTax 哪一页 / 状态（已核对 / 待核对 / 缺单据）**。数字都是**从已有记录算出来的参考值**，旁边始终有「以官方单据为准」。

| 汇总项 | 数据来源（小助手里） | 备注 |
|---|---|---|
| 工资（W-2 框 1）、联邦 / 州已扣税 | 手工录入 W-2（只录这几个数字） | 到账金额 ≠ 工资总额，不能自动推 |
| 利息 / 股息（美国、境外分开） | 收入账本：利息 / 股息 + 「境外来源」标记 | 对照 1099 |
| 卖出收益 | 收入账本「卖出类 + 其中已实现收益」 | 对照 1099-B；成本基础另核 |
| 租金收入 / 费用 | 房产（用途 = 出租）的收入和账单 | 折旧需手填一次 |
| 房贷利息 | 借贷：全年利息合计（按摊还表拆分） | 对照 1098 |
| 房产税 | 账单：房产税 + Escrow 里的房产税部分 | 对照 1098 / 税单 |
| IL 房产税抵免所需的房产税 | 同上（只算自住房） | |
| 医疗 / 捐款 / 教育 / 看护 | 带「税务标记」的花费 | 逐项 vs 标准扣除要比较，**由 TurboTax 做** |
| 退休 / HSA 供款 | 账户的年度供款记录（新增） | 对照 5498 / 8889 |
| 境外账户最高余额（每个账户）、合计 | 账户余额历史（标记为境外的） | **FBAR / 8938 预判，不是申报** |
| 已缴预缴税 / 去年结转 | 账单（income_tax）+ 手工 | |

交互：每行可展开看「由哪几笔记录加起来」，能点回原记录改；有「忽略这一笔」。**所有数字旁边写口径和日期范围**，避免误解。

## 7. 数据与技术方案

**7.1 税务规则数据文件**（`data/tax-rules.js`，随版本发布，不放数据库）

- 按税务年度分段：截止日、各表的阈值（FBAR、8938、赠与、标准扣除等）、IL 特有项；每条带 `source`（官方链接）、`verified`（核对日期）、`note`。
- 页面上每个数字旁都能点开看出处和核对日期；**超过 N 天没核对的年度显示「规则可能过期」黄条**。
- 变更只改数据文件 + 发版本，代码不改。

**7.2 新增数据（数据库，迁移一份；按「新表要进备份」规则接入备份恢复）**

| 表 | 内容 |
|---|---|
| `tax_years` | 年度、报税身份（合报）、居民身份标记（只存分类，不存证件）、软件（TurboTax）、是否延期、状态（收集中 / 汇总中 / 已报） |
| `tax_docs` | 年度 × 单据类型 × 是否已收到 × 存放位置备注（如「Google Drive / Tax 2025」）；**不存文件本身** |
| `tax_notes` | 年度内的自由备注（受限字数）；不存证件号 |
| 已有表加字段 | 账户 `is_foreign`（境外）、房产 `is_foreign`、收入记录 `foreign_source`、花费 / 账单 `tax_tag`（捐款 / 医疗 / 教育 / 看护 / 房产税…，**可空，默认不打标**） |
| 年度供款 | 账户 × 年度 × 供款额（退休 / HSA / 529） |

**7.3 权限**：沿用财务权限（只有有财务权限的成员可见）；家主可控制谁能看税务页。

**7.4 备份**：新表按项目约定接入备份 / 恢复；税务页导出的汇总里同样没有证件号。

**7.5 AI**：规则本身用确定性的数据文件，不让 AI「编税法」。若加「问咩咩」，只把脱敏后的汇总（金额、类别，不含姓名 / 账号 / 证件）和规则条目作为上下文，回答带「仅供参考」并引用数据文件里的出处。

## 8. 隐私与安全（硬性规则）

1. **永不存**：SSN、ITIN、报税 PIN、IP PIN、银行路由号 / 账号、TurboTax / IRS 账号密码、完整的出生日期 + 姓名组合（用于报税的那一套）。输入框也不提供这些字段。
2. 家属状况只存分类标记（例如「有 ITIN」「无 SSN」），不存号码。
3. 单据只记「有没有」和「放在哪」；**不上传 / 不存 W-2、1099 的图片或 PDF**（一期）。
4. 如果以后要存任何敏感文本：只能是**浏览器本地用口令加密**（Web Crypto，口令不上传、忘了无法找回），且默认关闭；这不属于一期。
5. 备份文件里同样不含上述内容；错误日志和 AI 请求里过滤税务字段。
6. 页面和导出都带「参考用，不是税务建议；以 IRS / 伊利诺伊税务局官方资料和报税软件为准」。

## 9. 分期

| 期 | 内容 | 依赖 / 风险 |
|---|---|---|
| **一期（先做）** | 税务目录页 + 数据文件（日历、单据清单、知识库、事件指南）+ 年度状态 + 单据清单 + 提醒进「今日」 | 不碰现有数据；零迁移风险；先把「别漏事」做起来 |
| **二期** | 打标记（账户 / 房产 / 收入 / 花费的境外和税务标记）+ 数字汇总表 + FBAR / 8938 预判（账户最高余额） | 需要迁移（加字段 + 新表）；先说清动多少条、怎么回退，线上跑前先问你 |
| **三期** | 事件指南与交易流程联动（卖房 / 卖车完成时自动算「成本基础 / 收益」参考、提醒存单据）；装修 / 改善记录（计入房产成本基础）；折旧；年度供款记录 | 房屋 / 车辆交易流程要加字段 |
| **四期（视需要）** | TurboTax 对照导出（CSV / 打印页，按访谈顺序）；往年对比；预缴额估算器（只做提醒级） | 估算类要特别写清不是申报 |

每期都是一个独立可用的小版本，按项目规则逐个发布；涉及数据库的单独一个版本。

## 10. 风险与取舍

- **税法会变、细则多**：全部放数据文件并标核对日期；不确定的写「待核对」，不凭印象；首版宁可少讲、讲准。
- **被当成税务建议**：全站「参考用」声明；不给「你该不该怎么报」的结论，只给「这是什么、谁可能要、去哪核对」。
- **汇总数字与官方单据不一致**：永远以单据为准；汇总表标「参考」，每行有来源明细和「已核对」勾选。
- **身份差异**：每个家庭的合报资格、居民认定不同；页面上先让家主确认前提（第 11 节），不做自动判定。
- **隐私**：见第 8 节；一期不存任何敏感文本。
- **范围蔓延**：不做报税软件；二期以后才碰数字汇总；加密存储作为独立评估，不绑在一期。

## 11. 需要你确认的问题

1. **身份细节**：两位都是税务居民吗（绿卡 / 住满天数）？有没有家属在报税时用 ITIN？有没有孩子（儿童税收抵免、IL 抵免）？
2. **海外账户 / 资产**：有没有中国（或其他国家）的银行 / 投资账户、保险、房产？合计在一年中最高是否可能超过 1 万美元？有没有境外收入（利息、租金）？
3. **收入构成**：除了 W-2 工资，有没有出租房、卖股票 / 基金、加密货币、自由职业、境外亲友的赠与或借款？
4. **扣除方式**：往年是标准扣除还是逐项？房贷利息 + 房产税是否常常超过标准扣除？（决定要不要重点做「逐项扣除的数字」）
5. **优先级**：先做一期（提醒 + 清单 + 知识库）可以吗？还是更想先要「数字汇总表」？
6. **谁能看**：税务页是否只对家主 / 有财务权限的成员可见？
