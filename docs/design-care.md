# 检查卡：把“建议做的任务”变成可判断的标准（已实现样板）

## 1. 问题

季节任务和设备只有一句备注，用户不知道：看什么、什么算正常、自己能做什么、什么情况该叫人、什么情况要马上处理、大概花多少钱。保养记录只记“做过什么”，不记检查结论，所以“检查发现有问题”之后没有下文。

## 2. 检查卡的结构（data/care.js）

每张卡按**设备类型 id** 或**季节任务 key** 索引：

```js
{
  check:  ["看什么 1", "看什么 2"],        // 可观察的迹象
  ok:     "正常是什么样",
  diy:    ["自己能做的动作、用什么耗材"],
  pro:    ["出现哪些情况就约师傅，约哪种工"],
  urgent: ["安全红线：立即处理 / 停用"],
  cost:   "费用区间（自己做 vs 请人，芝加哥行情）",
  when:   "频率和最佳时段",
}
```

展示：季节任务行和设备详情页各带一个「怎么查、什么时候叫人」折叠块；设备生成页的说明也从卡里取。

## 3. 检查结论 → 待办

保养记录的「检查」类型增加结论：正常 / 需保养 / 需维修 / 需更换。结论为后三者、且之后没有对应的保养 / 维修 / 更换记录时，设备进入“待处理”状态：卡片上标“检查发现问题”，首页出现“尽快 · 必须”提醒，直到记一条保养 / 维修 / 更换。不新增表，靠记录顺序判断。

## 4. 样板：车道

车道作为设备类型加入（`driveway_asphalt` 沥青、`driveway_concrete` 混凝土），房屋资料勾“自家车道”后推荐生成；季节任务加春季填缝检查、秋季封层 / 填缝。

### 沥青车道判断标准

| 动作 | 什么时候 | 判断标准 | 谁做 | 费用（芝加哥） |
|---|---|---|---|---|
| 首次封层 | 新铺后 6–12 个月 | 等沥青固化，太早封会软 | 请人或自己 | — |
| 填缝 crack sealing | 每年春秋各查一次 | 宽 1/8″–1″ 的裂缝都要填，目的是不让水进基层 | 少而小：冷灌缝剂自己做；多、宽、深：请人热灌 | $1–3 / 线英尺 |
| 封层 sealcoating | 每 2–4 年，冻融地区 2–3 年 | 表面发灰、细碎石外露、水不成珠；太勤会起皮 | 两车位自己买桶装刷两遍可行 | $0.15–0.30 / 平方英尺，两车位 $150–400 |
| 补丁 patching | 发现即做 | 坑洞、局部龟裂（面积 10% 以内） | 请人切除重铺 | $2–5 / 平方英尺 |
| 重铺面层 resurface | 通常 12–15 年 | 表面普遍磨损、脱粒、龟裂超过 25–30% 面积，但基层没问题（没有下沉、隆起、积水） | 请人，1.5–2″ 面层 | $2–4 / 平方英尺，再撑 8–12 年 |
| 整体更换 | 20–25 年以上或基层坏 | 大面积下沉或隆起、雨后 2 小时仍有超过 1/2″ 的积水、裂缝超过 1″ 宽、边缘大面积碎裂 | 请人，含基层 | $5–10 / 平方英尺 |

施工条件：气温 50°F 以上、24–48 小时不下雨，晚春到早秋。日常：第一年冬天不撒岩盐（用 CMA 或沙）、铲雪别用金属刃刮、夏天高温别长时间停重车、油渍先除油再封层、落水管不要直排车道、边缘用土和草皮托住。

### 混凝土车道

裂缝超过 1/4″、表面剥落（盐 + 冻融）、接缝错台要处理；错台用灌浆 / 发泡抬升比换便宜很多；每 3–5 年做一次渗透型防护剂；第一年冬天同样不撒盐。

## 5. 已配卡的任务 / 设备

沥青车道、混凝土车道、沥青瓦屋顶、暖风炉、热水器、排水泵、中央空调、排水槽清理（季节任务）、壁炉烟囱（季节任务）。其余任务按同一格式逐步补。
