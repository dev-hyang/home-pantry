# 随手问咩咩：房屋与账单页的就地指导（设计稿，2026-10-25）

## 1. 要解决的问题
房屋资料、交易清单、设备 / 车辆保养、季节任务、账单与花费这些页面，对没经验的人来说每一项都是「这是什么、为什么要做、怎么做、什么时候该叫人」。现在只有一个整页的「咩咩咩」入口（#/ai），离具体事项太远：用户要先记住自己在看什么，再跑去另一页重新描述。

同时又不能把每一行都变成聊天框：一页几十项，个个弹 AI，页面立刻变吵、费 token、还让人不敢点。

## 2. 三层设计：先静态、再展开、最后才问 AI
每一项（设备、保养项、季节任务、交易步骤、账单、花费图表）统一只有**一个很轻的入口**，展开后分三层，越往下越「重」，默认都是收起的：

```
┌ 🔥 暖风炉 · 换滤网 · 每 3 个月          [?]  ┐   ← 第 0 层：行本身，右侧一个小问号（或 ⓘ）
└──────────────────────────────────────────────┘
点 [?] 展开（就地，不跳页、不弹窗）：
┌ 为什么：滤网堵了风量小、费电，严重时压缩机过热。                        ┐  ← 第 1 层：静态一句话（数据表里写死，零成本、离线可用）
│ 怎么做：关机 → 抽出旧滤网看尺寸（如 16×25×1）→ 箭头朝气流方向装新的。 │
│ 什么时候叫人：机器有异响 / 烧焦味 / 吹不热，别自己拆。                  │
│ ⏱ 10 分钟 · 💲 滤网 $10–20 · 🔧 自己能做                               │
│ [问咩咩：我家这台怎么弄？]   [复制提示词]                               │  ← 第 2 层：带上下文的 AI 问题，点了才去问
└──────────────────────────────────────────────────────────────────────┘
```

- **第 1 层永远有**：哪怕用户没填 AI key、断网，也能看到「为什么 / 怎么做 / 何时叫人」。这是给小白最稳的东西，内容写在数据表里（见 §5），不依赖 AI。
- **第 2 层按钮才调 AI**：按钮文案是具体的问题（不是泛泛的「问 AI」），prompt 自动带上这一项的上下文（见 §4），答案就地显示在展开区里，页面其他部分不变。
- 没 key 时按钮变成「复制提示词」，和现在整页咩咩咩一样走方案 D。

一句话：**问号只有一个，默认收着；静态说明先顶上；AI 是最后一层，而且问题替用户写好了。**

## 3. 放在哪里（第一版覆盖这些）
| 页面 | 挂在哪一项上 | 第 1 层静态内容来自 | 第 2 层默认问题（prompt 标题） |
|---|---|---|---|
| 房产 → 房屋资料 | 每一块（保险、HOA、应急信息、关键位置、责任归属） | `data/house.js` 各块 `desc` + 新增 `guide` | 「我这种房型（{kind}/{role}）这一块该填什么、去哪找？」 |
| 房产 → 交易（买 / 卖 / 租赁归还）清单 | 每个步骤 | `data/deals.js` 每步新增 `why / how / pro` | 「{房产} 的『{步骤}』：现在该做什么、找谁、要注意什么？」 |
| 设备档案 / 保养记录 | 每台设备 + 每个保养项 | `data/house.js` 设备表新增 `care: {why, how, pro, diy, cost, mins}` | 「{设备}（{年限}年，上次保养 {日期}）这项保养怎么做？要不要叫人？」 |
| 车辆 → 保养清单 / 检查卡 | 每个保养项 | `data/care.js` 新增同上 | 「{车型} {里程} 的『{项目}』自己做还是去店里？大概多少钱？」 |
| 房屋 → 季节任务 | 每条任务 | `data/house.js` 季节任务新增 `why / how / pro` | 「{月份}{任务}怎么查？发现什么情况要叫人？」 |
| 账单 → 某条账单 | 枢纽页顶部一个问号 | 账单分类的固定说明（`data/bills.js`） | 「这条 {分类} 账单 {金额}/{周期}，和同地区比贵不贵？怎么省？」 |
| 账单 → 花费 | 图表标题旁一个问号 | 无静态层，直接第 2 层 | 「这 {n} 个月花费从 {a} 涨到 {b}，主要是 {前三类}，是什么原因？怎么控？」 |
| 首页注意事项 | 每条提醒行末 | 复用提醒对应项的静态内容 | 同对应项 |

第二版再加：采购清单（为什么推荐这个量）、预算（为什么超了）、信用卡推荐（为什么推这张）。

## 4. 上下文怎么带（prompt 模板）
每个入口有一个 `ask` 描述：`{ kind: "care", id, title, context() }`。点按钮时拼成：

```
[系统] 你是家庭生活助手……（沿用 core/ai.js generalPrompt 的 system）
      这次只回答一个具体事项，格式：先一句结论，再「怎么做」3–6 步，最后「什么时候叫人 / 风险」。不要泛泛而谈，控制在 200 字内。
[用户] 事项：暖风炉 · 换滤网
      我家的情况：独栋 · 自住 · 伊利诺伊 · 暖风炉 2014 年装（11 年）· 上次保养 2026-04 · 滤网尺寸未填
      问题：这项保养怎么做？要不要叫人？
```

规则：
- **只带这一项相关的字段**（房型、责任归属、地区、设备年限、上次日期、金额、周期、里程），不带备注、人名、账号、地址门牌。沿用整页咩咩咩那个「附带家里的情况」开关的隐私边界，但范围更小。
- 字段缺失就写「未填」，让 AI 顺带提醒去填，这本身就是引导。
- 地区取 `Units.region` + 房产所在州（如果填了），因为「叫谁、多少钱」和地区强相关。
- 答案限制在 200 字左右（system 里说明），避免展开区变成长文。

## 5. 静态内容怎么来（第 1 层）
在现有数据表上加字段，不新建系统：

```js
// data/house.js 设备表（示例）
{ id: "furnace", name: "暖风炉", …,
  care: [
    { id: "filter", name: "换滤网", every: 3,
      why: "滤网堵了风量小、费电，严重时压缩机过热。",
      how: "关机 → 抽出旧滤网看尺寸（如 16×25×1）→ 箭头朝气流方向装新的。",
      pro: "有异响、烧焦味、吹不热：别自己拆，叫 HVAC 技师。",
      diy: true, mins: 10, cost: "$10–20" },
    …
  ] }
```

- 先用中文写，`i18n/en.js` 照常翻译。
- 第一版先覆盖**提醒最常触发的 30 项**（滤网、烟雾报警器电池、热水器放水、排水沟、冬季关水龙头、换机油、轮胎气压、刹车片、交易里的验房 / Title / 过户水电、账单里的 HOA / 房产税 / 保险）。没写的项只显示第 2 层按钮，不显示空的第 1 层。
- 内容可以让 AI 先起草（像用卡模块那样「AI 起草，人核对」），我起草后你过一遍。

## 6. 不让它 overwhelming 的规则
1. **一行只有一个入口**，就是行末的小问号，灰色，不抢眼；没有「AI」字样刷屏。
2. **展开是就地的**，不跳页、不弹模态；再点问号收起。同一时间只展开一项（展开新的会收起旧的）。
3. **第 1 层先出**，第 2 层要再点一次。大部分问题看完第 1 层就不会去点 AI。
4. **答案留在原地**，带「复制」「收起」；不进入聊天模式，没有多轮对话——想追问就去整页咩咩咩，那里会预填这次的问题和答案摘要。
5. **记住回答**：同一项的答案存本机（`localStorage`，按 ask id），7 天内再展开直接显示上次的，不重复花钱；旁边有「重新问」。
6. **额度保护**：沿用 `aiQuota()`；额度用完按钮自动变「复制提示词」。
7. **列表页不预渲染内容**：第 1 层文字在点开时才插入 DOM，几十项的页面不会变重。
8. 手机上展开区占满行宽，按钮整行；电脑上展开区跟在行下面，宽度跟行一致。

## 7. 实现要点
- 新模块 `js/core/ask.js`：`askButton(ask)` 画问号；`askPanel(ask)` 画展开区；`runAsk(ask)` 拼 prompt → `askText()` → 存本机 → 重画那一块。`ask = { id, title, guide?: {why, how, pro, diy, mins, cost}, question, context: () => string[] }`。
- 各页只做一件事：在行里 `${askButton({...})}`，并在数据表里补 `guide`。
- 事件：`data-action="ask-toggle" / "ask-run" / "ask-copy" / "ask-more"`，和现有 click 分发一致。
- 「ask-more」跳 `#/ai?from=<askId>`，整页咩咩咩预填问题 + 已有答案，方便追问。
- CSS：`.ask-btn`（22px 圆形问号）、`.ask-panel`（浅色底、左侧 3px 色条、`why/how/pro` 三行用小图标 ❓ 🔧 ☎）。
- 本机缓存 key：`hmh-ask.<id>`，值 `{ at, q, a }`。

## 8. 分期
- **第一期（1 天）**：`ask.js` + 样式 + 设备保养项 / 季节任务 / 车辆保养三处接入 + 30 条静态内容 + 花费图表问号。
- **第二期**：交易清单每步、房屋资料各块、账单枢纽页、首页注意事项。
- **第三期**：采购、预算、信用卡；整页咩咩咩的「从某项跳来」追问。

## 9. 不做的
- 不做悬浮聊天气泡、不做每页常驻对话框。
- 不做自动触发（页面一打开就问 AI）。
- 不把备注、人名、账号、地址发给模型。
