# 我的 → 家里的数字（2026-11-06，原「统计」重做）

花费统计早就搬到 财务 → 花费，「统计」只剩一张消耗趋势，看不出它是干什么的。现在这一页只讲家里的事，不讲钱：

| 块 | 看什么 | 数据 |
|---|---|---|
| 年度回顾 | 今年用掉 / 补货 / 新物品 / 保养 / 季节任务 / 扔掉的次数；最常用的东西、最勤快的补货员、最忙的一天 | 库存日志（近一年）、物品、保养记录、季节任务完成记录 |
| 最常用 | 近 90 天按「用掉」次数的 Top 10；单品每周用量与库存（原来的图） | 库存日志 |
| 补货节奏 | 补过 2 次以上的物品：平均几天补一次、预计几天后用完（库存页同一套估算），按快用完排 | 库存日志 restock + 物品估算 |
| 谁在出力 | 近 6 个月每月每人记了几次；今年每人用掉 / 补货 / 扔掉 | 库存日志 created_by |
| 保养与季节任务 | 近 12 个月季节任务每月完成 / 没完成（全部在用房产）、保养记录每月按类型 | seasonal_tasks、maintenance_logs |
| 一周节奏 | 周一到周日 × 五个时段的热力格（用掉 + 补货） | 库存日志 |
| 浪费 | 每月扔掉几件、扔得最多的东西 | 库存日志 discard（迁移 065） |

- 读数：近一年的库存日志只在打开这一页时读一次（按 1000 行一页），10 分钟内来回切换不重读；其余都是内存里已有的表。
- 浪费：过期的物品卡和储藏概览的「先吃这些」里多一个「🗑 扔掉」，把剩下的记成 discard；不算进日均用量（logic.js 只看 consume）。要先执行迁移 065。
